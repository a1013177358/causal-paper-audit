# 实证论文因果识别审计

为需要在组会、文献综述或研究设计中引用实证证据的读者，回答：
**什么变化、对谁、相对什么、在哪段时间内，得到了哪一种强度的证据？**

输入是论文全文、合法片段或已定位的图表，以及读者要核查的问题。
输出是一份带原文定位的中文审计。没有原始数据时，只核查论文论证，不能声称重做估计。

## 1. 先检查材料能支持哪些判断

- 识别题名、版本、材料范围和缺失部分。只有摘要、图注或截图时，不补想象中的方法、表格或检验。
- 建立证据位置：优先原有页码、章节、表格与列号；有段落编号就引用编号。
- 分开保留三层：**原文报告的事实／审计者基于事实的判断／当前不能确定的内容**。
- 原文数字、样本量、年份或模型标签冲突时列出冲突的两处位置，保留原文，不擅自选一个修正。
  某处缺信息只说明该处不能验证，不直接判定整篇研究无效。

## 2. 重建识别设计，再读显著性

先写一句估计对象：处理或暴露、结果变量、目标人群、比较组、时间范围、估计量与分析样本。
对照实际方法选下面相关检查；不要把所有方法的检查机械套给每篇论文。

| 设计 | 优先核查 |
| --- | --- |
| RCT | 分配单位、分层或批次、处理实际定义、遵从、退出和替补、分析样本；ITT/按处理分析的区别 |
| DID/事件研究 | 处理时点、对照组、是否错位实施；平行趋势与无预期假设；前趋势不显著不能证明平行趋势 |
| IV | 明确工具的构造、第一阶段及弱工具证据；区分相关性与排除限制/外生性；过度识别或弱工具检验不能证明排除限制 |
| RD | 阈值、带宽、操纵与连续性证据，结论局限于阈值附近 |
| 观察性回归 | 控制变量、固定效应与未观测混杂；显著性和稳健性本身不能消除选择偏差或反向因果 |

随机化或识别的单位、观测单位和标准误聚类单位分别记录。
重复访谈、面板行数、交易数都不自动等于独立被试数。
退出率相近、均衡性检验不显著不等于选择问题已被证明不存在；说明作者提供了哪些支持和仍需哪些条件。

## 3. 给关键结论逐条建立证据账本

挑选足以支持读者实际引用的关键结论，每条写清：

1. **原述与位置**：原文短引或忠实转述，附段落或表格列位置。
2. **证据**：设计、相应估计值、单位、样本与不确定性；没有就写未提供。
3. **判定**：在明确条件下可作因果解释／条件性支持／相关或机制线索／材料不足。
4. **可引用改写**：保留处理、人群、时窗和不确定性，不把边界留在脚注里。

账本覆盖主结果，也保留对读者结论有影响的零结果、反例和限制。
不强制给每篇论文相同条数，不输出没有校准依据的“可信度百分比”。

## 4. 检查最容易扩大的四种结论

- **效应量**：系数对应哪个模型、列和控制组？概率变化是百分点还是相对百分比？
  指数、对数、标准化量、Probit系数和边际效应各自说明；没有换算依据不硬算。
  如做换算，列出公式、原始数值和对应规格，不混用正文、不同回归列或图中结果。
- **零结果**：“未发现显著变化”不等于“证明无效/绝对安全/等效”。只有给定界值与相应区间、功效等证据时再谈排除效应。
- **机制**：处理可能随机，处理后的中介未必随机。收入、行为和结果同时变化或时序一致通常只是机制线索；没有额外设计就不声称中介因果效应已识别。
- **外推**：一个地点、人群、产品、剂量或短时窗，不自动支持普遍政策、长期效果或临床健康结论。
  自报量表不能自动替代未测量的临床或生物指标。

## 5. 交付前核对

逐条回到原文检查结论、单位和位置；明确图只读了图注还是读到了图形数据。
输出包括：材料范围、设计卡片、证据账本、限制与下一步核查。
引用可定位到提供的原件，不把外部常识伪装成论文做过的检验。
补充阅读建议必须针对影响当前判断的具体缺口；不要求为了完成阅读审计重新做整套科研实验。

如果材料不足，先交付可以核查的部分，再具体请求方法页、相关表格/附录或版本信息。
即使请求者要求确定结论，也不能编造缺失的识别假设、检验统计量和原始运行记录。
