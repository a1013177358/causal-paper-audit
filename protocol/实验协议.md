# 预先固定的实验协议 v1.2

目的：检验同一经济金融实证阅读任务，固定工作流是否改善关键边界覆盖与可核查性；允许无改善或退化。

宿主：Codex CLI 0.166.0-alpha.5.1；模型标识 gpt-6.1-sol；推理设置 ultra，与本机已配置设置一致。精确服务端模型快照及货币费用无法取得：CLI不提供可验证的快照版本/账单。保存可取得的token用量与墙钟时间，不把费用填0。

每次通过新 codex exec 会话执行，不resume/fork，不共享中间答案。忽略用户config，指定同一模型和推理设置；工作根为空目录，关闭项目文档注入。不联网、不调用工具，原文均直接放入提示词。A各组基础任务和材料逐字相同，唯一差异是是否加入固定Skill。两组顺序交错以降低时间批次差异，不故意弱化基线。

两组均显式关闭 memories 的使用和生成、技能搜索与自动技能说明，开启跳过宿主技能发现；将目标Skill的自动加载设为false。with只通过输入中的loaded_skill加载固定全文，without不提供它。完整实际参数保存在每次metadata.json。未重设HOME或CODEX_HOME，未复制凭证。

模型输入：基础任务＋本组额外Skill（仅with）＋原始材料；不提供验收标准、参考答案、其他运行输出、主办方打分细则或获奖目标。

每次墙钟上限600秒；各组相同；超时、拒绝、工具误用或输出失败均保留。计划A两组独立公平对照（4次），B两次独立复用，C两次独立异常测试，共8次。若环境无法运行，不伪造结果；切换宿主需重新固定协议并两组一致重跑，保留失败。

输出保留原始stdout JSONL、stderr、实际提示词、未经修正的final.md及元数据。内容核查后不修写模型原始结果；整理者的修正单独记录。文件哈希及实验启动UTC时间在lock.json固定；测试开始后不修改Skill、任务、材料或验收标准。

本轮不是统计功效充足的随机试验。两个A对照只支持本任务观察到的差异，不支持显著性或对所有论文/模型的因果推广。公平对照的额外Skill文字/token开销计入记录；尚无盲评或第三方独立复现。
