# Causal Paper Audit · 实证论文因果识别审计

一篇论文中的主效应、机制解释和零结果，能够支持的结论通常不同。本项目把“理解论文”落到一张可核查的证据账本：研究实际比较了什么，每条判断对应哪段原文，可以引用到什么程度，还缺什么材料。

面向经济金融实证研究的组会、文献综述和研究设计。交付物是可直接加载的 Skill、真实阅读案例、固定任务与原始运行记录。它不重跑原始数据，也不自动证明一篇论文的识别有效。

## 从哪里开始

- 方法与案例：[技术说明](技术说明.md)。
- 实际实验结果：[结果与限制](结果与限制.md)。
- Skill：[SKILL.md](skill/SKILL.md)。
- 论文输入与来源：[materials](materials/)。
- 事先任务和验收标准：[protocol](protocol/)。
- 未经改写的模型结果与日志：[runs](runs/)。

## 一个完整的阅读流程

1. 提供有权使用的论文或片段，声明材料版本和范围。
2. 在 Agent 中加载 `skill/SKILL.md`，再提交阅读任务与原文。
3. 先重建处理、比较组、人群、时窗、估计对象和样本流程。
4. 为主结果、机制和零结果逐项记录“原文位置—证据—判断—可引用改写”。
5. 回到原文核对单位与边界；缺材料时交付可判断的部分，并明确下一步要读什么。

Skill 无需独立服务或付费依赖。可将全文作为当前会话的工作流指令加载；在支持原生 Skill 的宿主中按该宿主的规范安装。不要把其他会话答案或本项目验收标准交给被测模型。

## 案例：五周还款是否降低金融压力

主案例是 Field、Pande、Papp 与 Park（2012）的印度小额信贷随机实验：

- 处理是**每五周**还款相对每周还款，原文简称“monthly”；不是自然月还款，也不是获得贷款相对不借款。
- 分配在贷款小组层面进行；约 5000 次重复调查来自 200 位分析客户。压力指数回归实际使用 4928 条观测、68 个贷款组。
- 表1 Panel A 第(1)列的系数是指数尺度上的 −0.093，SE 0.0442。指数变化、相对百分比和概率百分点不能混用。
- 收入和投资的变化支持作者讨论机制，但处理后的收入并未因此自动变成随机中介。
- “未发现违约显著增加”不能直接改写为“证明不会增加违约风险”。

这些是根据原文整理的案例说明，不冒充模型实测发现。模型实际回答、缺项和错误保留在 `runs/`，实测差异单独列在结果文件。

## 如何复做本篇的首组对照

本技术分享只展示A的第一组公平对照，材料包保留该组全部真实输入、输出与必要日志。完整研究的其他案例不在本篇结果声明范围内。

本轮使用 Codex CLI `0.166.0-alpha.5.1`、模型标识 `gpt-6.1-sol`、推理设置 `ultra`。任务为文本阅读，不开放工具或联网；两组使用相同原文、任务、基础权限和时间上限，区别仅为是否在输入中加入固定 Skill。

每次通过全新的 `codex exec` 进程执行；关闭已记录的技能/记忆自动注入入口，不复用会话答案。协议、文件哈希、启动时间与实际命令均随包保留。实验脚本记录的是本机 macOS 的 CLI 路径；在其他机器上须将执行文件路径改为本机路径，并重新记录环境。使用其他模型或设置时是新的实验，不能当成本轮独立复现已完成。

最简手动复做：打开两个独立会话，向两者提供相同的 `protocol/task_A.md` 和 `materials/A_paper.txt`；仅向其中一个提供固定 Skill。保留全部原始输入输出、时间、失败、额外资源与修正，再按预先标准逐项核查。若使用支持记忆或自动技能发现的宿主，应先明确关闭相应入口。

## 输入转换的范围

本技术分享材料包保留本案例期刊JATS原件和实际使用的论文文字及表格，附来源与原件哈希；阅读文本保留摘要、正文、段落位置及表格行列；合并表头按覆盖的各列展开。图只包含图注，公式明确标为未转换，并保留原件位置。读到图注不等于核查了图形数值；未转换公式也不能被说成论文未报告公式。
